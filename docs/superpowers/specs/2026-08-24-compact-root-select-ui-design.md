# 精简模式根目录选择器 UI 设计

## 目标

将精简模式左右文件栏中的多根目录选择器，从浏览器原生 `<select>` 替换为项目统一的自定义选择器，使触发框和展开菜单与右上角语言切换、文本编辑器语法高亮选择器保持一致。菜单使用圆角弹出层、悬停高亮和当前项勾选，不再出现由操作系统绘制的直角菜单。

## 范围

- 同时修改精简模式左栏和右栏，因为它们复用同一个 `FilePane` 组件。
- 仅在映射了多个根目录且 `showRootSelector` 开启时显示选择器。
- 只有一个根目录时继续显示现有的 `/` 根标记。
- 完整模式继续使用特殊根目录页面和面包屑入口，不增加根目录下拉框。
- 不修改根目录数据、当前目录状态、双栏绑定、模式切换或后端接口。

## 方案

在 `FilePane` 中复用 `components/ui/select.tsx` 提供的 `Select`、`SelectTrigger`、`SelectContent`、`SelectItem` 和 `SelectValue`：

1. 将根目录列表作为选择器项目，使用根目录 ID 作为值、名称作为显示文本。
2. 触发按钮保留当前根目录的可访问名称和栏内布局宽度，并采用项目现有的小尺寸圆角样式；过长名称在触发按钮内截断，不撑宽文件栏。
3. 弹出菜单与触发按钮左侧对齐，宽度至少覆盖触发按钮；菜单受可用视口高度限制，根目录过多时内部滚动。
4. 每个菜单项使用现有圆角悬停高亮，当前根目录显示勾选标记。
5. 选择新根目录后调用现有 `onRootChange(rootId)`。后续将路径重置为根目录、加载文件和激活对应栏的逻辑保持现状。

复用统一选择器可以直接继承现有视觉、键盘导航、焦点管理和弹出层定位。继续使用原生 `<select>` 无法稳定修改操作系统菜单的圆角；另写一套菜单则会重复已有组件和交互逻辑，因此不采用。

## 交互与可访问性

- 鼠标点击触发按钮打开菜单，点击项目切换根目录并关闭菜单。
- `ArrowUp`、`ArrowDown`、`Enter`、`Escape` 和文字检索沿用统一选择器行为。
- 触发按钮继续使用现有“左栏根目录”或“右栏根目录”无障碍名称，测试和辅助技术仍可按 `combobox` 定位。
- 空根目录列表或尚未选中有效值时不主动调用切换回调；现有初始化流程负责选择首个根目录。

## 验证

- 组件测试确认多根目录时渲染统一选择器、菜单包含全部根目录、当前项被选中，并且选择另一项只调用一次 `onRootChange`。
- 现有单根目录 `/` 标记测试和完整模式无选择器测试继续通过。
- 样式测试确认文件栏根目录触发器具备受限宽度，弹出菜单使用统一圆角菜单且可滚动。
- 运行完整前端测试、ESLint 和生产构建。
- 在当前测试服务中用真实浏览器检查左右栏菜单的圆角、悬停、勾选、长名称和根目录切换，并确认无运行时错误。
