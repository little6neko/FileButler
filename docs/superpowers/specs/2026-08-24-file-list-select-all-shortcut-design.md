# 文件列表全选快捷键设计

## 目标

在文件选择区域使用 `Ctrl+A` 或 `Cmd+A` 时，全选当前活动文件列表，而不是触发浏览器的整页文字选择。输入控件和文本编辑器继续使用自身的全选行为；其他应用窗口、面板或弹窗中的非编辑区域则只阻止浏览器全选网页文字，不选择后台文件。

## 现有能力

文件列表表头已有“全选可见文件”复选框，其动作最终调用当前浏览会话的 `selectionStore.selectAll(true)`。精简模式已经维护活动的左栏或右栏，完整模式已经维护当前激活窗口及其文件会话。现有全局快捷键路由负责 `Ctrl/Cmd+C`、`X` 和 `V`，并会排除输入框及 `contenteditable` 编辑区域。

## 快捷键路由

在现有全局文件快捷键路由中增加 `A` 分支，处理顺序如下：

1. 仅处理按下 `Ctrl` 或 `Cmd`、没有按下 `Alt` 且尚未被其他组件处理的按键。
2. 如果事件来自 `input`、`textarea`、原生 `select` 或 `contenteditable`，立即退出，不调用 `preventDefault()`。CodeMirror 因此继续全选当前文档，文本输入框继续全选自身内容。
3. 对其他位置的 `Ctrl/Cmd+A` 调用 `preventDefault()`，统一阻止浏览器选择整个网页的文字。
4. 如果页面级弹窗、活动文件窗口的本地弹窗、菜单或列表型弹出层正在显示，只阻止默认行为，不改变任何文件选择。
5. 否则，如果当前活动对象对应文件浏览会话，则调用该会话的 `selectionStore.selectAll(true)`。
6. 如果当前活动对象是 PowerRename、媒体预览、文本编辑窗口或其他非文件窗口，则不执行文件选择。

该分支不会显示提示，也不会把第二次快捷键解释为取消全选。

## 当前列表语义

- 精简模式：当前活动的左栏或右栏。
- 完整模式：当前激活的文件浏览窗口；其他文件窗口不受影响。
- 当前目录中的文件夹和文件全部纳入选择，与表头“全选可见文件”完全一致。
- 空目录只阻止浏览器默认文字全选，不产生其他状态变化。
- 特殊根目录目录卡不属于普通文件选择列表，不会被该快捷键选中。

## 保持不变

- CodeMirror 的 `Ctrl/Cmd+A`、保存、查找、撤销和其他快捷键不变。
- 输入框、文本域和原生选择控件的原生快捷键行为不变。
- 文件复制、剪切和粘贴快捷键逻辑不变。
- 鼠标单选、多选、范围选择、框选和表头复选框行为不变。

## 验证

- 工作区测试确认精简模式只全选活动栏，并覆盖 `Ctrl+A` 与 `Cmd+A`。
- 工作区测试确认完整模式只全选当前激活文件窗口。
- 测试确认输入框和 CodeMirror 不被全局 `A` 分支阻止或改变文件选择。
- 测试确认非文件窗口及打开的弹窗只阻止浏览器默认行为，不选择后台文件。
- 运行完整前端测试、ESLint 和生产构建。
- 在真实浏览器中验证文件行全部选中、页面文字不产生浏览器选区，并检查文本编辑器和其他窗口行为。
