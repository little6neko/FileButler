# 完整模式媒体完整适配设计

## 目标

完整模式中的媒体预览窗口始终完整显示当前图片或视频。无论媒体是竖向、横向或超宽比例，也无论用户如何缩放、最大化或还原窗口，预览区都不得出现横向或纵向滚动条。

## 范围

- 仅修改完整模式的媒体应用窗口。
- 精简模式继续使用当前随媒体和浏览器视口约束尺寸的弹窗，不修改其布局与溢出行为。
- 图片和视频采用相同的完整适配规则。
- 不改变窗口尺寸、位置、最小尺寸、拖动、缩放、最大化或最小化行为。
- 不改变媒体目录快照、左右切换按钮、悬停动画或首尾禁用逻辑。

## 方案

在完整模式媒体窗口的专属选择器下覆盖公共预览样式：

1. 媒体窗口布局和预览内容继续占满标题栏之外的可用空间，并保留 `min-width: 0` 与 `min-height: 0`，允许其随窗口收缩。
2. 完整模式预览内容使用 `overflow: hidden`，不创建任何滚动容器。
3. 图片和视频的渲染盒占用预览内容的可用宽高，并通过 `object-fit: contain` 保持原始宽高比。媒体完整包含在可用区域内，剩余空间作为居中留白。
4. 左右导航按钮仍绝对定位在预览内容上方，不参与媒体尺寸计算。

本方案使用浏览器原生布局完成自适应，不读取媒体像素尺寸，也不监听窗口变化执行 JavaScript 计算，因此窗口连续缩放时不会产生额外状态或尺寸同步问题。

## 边界行为

- 竖图在较矮窗口中按高度缩小，左右留白。
- 超宽图在较窄窗口中按宽度缩小，上下留白。
- 视频连同原生控制条包含在媒体渲染盒内，不因固有分辨率撑大预览区。
- 媒体加载失败时沿用浏览器当前的失败表现，不新增错误界面。
- 极小窗口仍受现有媒体窗口最小尺寸约束；媒体继续缩小到该窗口的可用内容区域。

## 验证

- 样式测试确认完整模式预览区使用 `overflow: hidden`，媒体采用占满可用盒和 `object-fit: contain`。
- 现有媒体预览与目录切换测试继续通过。
- 在真实浏览器中分别打开竖图、超宽图和视频，缩小及最大化完整模式窗口，检查媒体边界始终位于预览区内，并确认 `scrollWidth === clientWidth`、`scrollHeight === clientHeight`。
- 打开精简模式媒体弹窗，确认其当前尺寸与布局未受此次专属样式影响。
