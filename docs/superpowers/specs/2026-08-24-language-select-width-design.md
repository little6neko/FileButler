# 语言选择器宽度统一设计

## 背景

语言选择器触发框当前宽度为 `118px`。通用 `Select` 菜单会跟随触发框宽度，但同时具有 `144px` 的最小宽度，因此语言菜单实际展开为 `144px`，左右边缘与触发框不一致。

## 设计决定

采用视觉对比中的 B 方案：将语言选择器触发框宽度调整为通用 Select 的标准最小宽度 `144px`。菜单继续使用现有的触发框宽度变量和 `144px` 最小宽度，最终触发框与菜单均为 `144px`。

该方案不新增任务栏专属宽度覆盖，也不改变通用 `SelectContent` 的接口或默认样式。语言选择器由完整模式、精简模式以及登录相关页面共用，因此这些位置将保持一致的 `144px` 宽度。

## 保持不变

- 菜单右侧继续与触发框右侧对齐。
- 菜单与任务栏继续保持现有间距。
- 约 `100ms` 的打开和关闭动画不变。
- 遮罩、任务栏、任务面板和语言菜单的 `50 / 60 / 70 / 80` 层级不变。
- 自动、English、简体中文三个选项及语言切换逻辑不变。
- 根目录和文本语法等其他 Select 不受影响。

## 验证

- 组件测试确认语言触发框使用 `144px` 标准宽度。
- 真实浏览器中打开语言菜单，确认触发框与菜单计算宽度均为 `144px`，左右边缘对齐。
- 确认语言菜单动画、层级和选项切换仍正常。
- 运行完整前端测试、ESLint 和生产构建。
