# 任务栏浮层层级与语言菜单动画设计

## 目标

修正右上角语言选择菜单和任务侧栏被任务栏及其阴影遮挡的问题，并为语言菜单启用与项目其他自定义选择器一致的淡入淡出动画。任务侧栏仍从任务栏下方开始，任务栏按钮继续保持可见和可点击。

## 层级体系

项目现有普通 Dialog、Sheet、Select 和 Tooltip 使用层级 `50`。新增语义化 CSS 变量，将系统界面依次放在公共浮层之上：

| 界面层 | 层级 | 用途 |
| --- | ---: | --- |
| 普通浮层 | `50` | 保持现有组件默认值 |
| 任务栏 | `60` | 始终位于普通页面弹窗和遮罩上方 |
| 任务侧栏面板 | `70` | 覆盖任务栏向下投射的阴影 |
| 任务栏语言菜单 | `80` | 同时高于任务栏和已打开的任务侧栏 |

任务栏当前的 `100000` 改为 `60`。数值只表达相对顺序，不改变布局或性能；较小且连续的层级便于后续维护。

## 语言选择菜单

右上角语言选择器继续复用统一 `Select` 组件，但采用任务栏专属定位配置：

1. 关闭“选中项与触发按钮对齐”模式。该模式当前会通过 `animate-none` 主动禁用菜单动画。
2. 菜单右侧与触发按钮右侧对齐，并增加足够的底部偏移，使菜单从 44px 任务栏下方出现，不与任务栏实体重叠。
3. 启用统一 Select 已有的约 100ms 打开和关闭动画：透明度渐变，同时保留轻微缩放过渡。
4. 为 `SelectContent` 增加可选的定位层类名接口，只将任务栏语言菜单的 Positioner 提升到层级 `80`。不全局抬高窗口内部的根目录、语法高亮等其他选择菜单。

语言选项、当前值、自动语言逻辑和切换回调均不改变。

## 任务侧栏

- `.jobs-sheet-content` 保持 `top: 44px` 和 `height: calc(100dvh - 44px)`，不会覆盖任务栏。
- 仅将侧栏面板提升到层级 `70`，使其顶边和背景覆盖任务栏阴影。
- Sheet 遮罩继续使用普通层级 `50`，位于任务栏下方。任务栏因此不会被遮罩拦截，任务按钮、窗口按钮和模式切换按钮仍可点击，并继续触发现有的关闭任务侧栏逻辑。
- 当任务侧栏和语言菜单同时打开时，语言菜单位于最上方。

## 边界行为

- 语言菜单靠近浏览器右边缘时按右侧对齐，不越出视口。
- 菜单关闭动画完成后再由统一组件卸载，不引入额外 React 状态或定时器。
- 精简模式和完整模式共用同一任务栏，因此两种模式使用相同层级与动画。
- 不修改其他 Dialog、Sheet、Select、Tooltip、窗口内弹窗或右键菜单的默认层级。

## 验证

- 组件测试确认语言菜单关闭触发项对齐模式、使用右对齐和任务栏专属 Positioner 类，并保留正常语言切换。
- 样式测试确认公共浮层、任务栏、任务侧栏和语言菜单依次使用 `50 / 60 / 70 / 80`；任务侧栏的顶部和高度约束保持不变。
- 运行完整前端测试、ESLint 和生产构建。
- 在真实浏览器中确认语言菜单的打开与关闭动画存在，菜单顶边不被任务栏遮挡，并检查 `语言菜单 > 任务侧栏 > 任务栏 > 遮罩` 的计算层级。
- 同时打开任务侧栏和语言菜单，检查任务侧栏不再被任务栏阴影压住，任务栏按钮仍可点击，页面无运行时错误。
