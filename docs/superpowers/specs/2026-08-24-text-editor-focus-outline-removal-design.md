# 文本编辑器内部聚焦框移除设计

## 目标

完整模式和精简模式中的文本编辑器都不再绘制 CodeMirror 自身的蓝色聚焦外框，使编辑区域边缘保持简洁一致。本规范取代此前“仅完整模式隐藏、精简模式保留”的差异化规则。

## 范围

- 同时影响完整模式文本编辑窗口和精简模式文本编辑弹窗。
- 不修改完整模式窗口外层的激活边框。
- 不修改精简模式弹窗自身的边框、遮罩或关闭行为。
- 不修改文本光标、当前行高亮、文本选区、语法高亮、输入、快捷键及保存行为。
- 不为鼠标聚焦和键盘聚焦设置不同样式。

## 方案

删除文本编辑器通用的 `.cm-focused` 外框样式，以及不再需要的完整模式专属 `outline: none` 覆盖。文本编辑器内部因此在所有容器中都不绘制聚焦外框，同时保留 CodeMirror 原有的焦点状态和编辑行为。

该方案比保留浅色边框更符合“删除聚焦框”的目标，也比仅在键盘聚焦时显示边框更简单、一致。差异只涉及 CSS，不向 React 组件增加模式参数、焦点状态或条件渲染。

## 交互与边界行为

- 点击或用键盘进入编辑器后，仍通过光标、当前行高亮和选区反馈当前编辑位置。
- 完整模式窗口聚焦后，继续显示窗口外层蓝色激活边框，但编辑区内部没有第二圈边框。
- 精简模式弹窗聚焦后，弹窗边界保持现状，但编辑区内部没有蓝色边框。
- 在工具栏、语法选择器和编辑区之间切换焦点时，不新增其他视觉替代标记。

## 验证

- 更新样式测试，确认文本编辑器不再定义 `.cm-focused` 外框，也不保留完整模式专属覆盖。
- 运行完整前端测试、ESLint 和生产构建。
- 在真实浏览器中分别打开完整模式和精简模式文本编辑器，聚焦编辑区后确认计算样式不绘制 `outline`，同时验证光标、当前行、选区和输入正常。
