# 115 网盘与传输进度设计

## 目标与确认范围

在 FileButler 中增加独立的 115 网盘窗口，与现有本地文件窗口联动。桌面应用图标纵向排列，不改变文件窗口的自由布局。复用现有认证、窗口管理、任务面板和 SSE 完成通知，不改变“任务完成后刷新目录”的行为。

用户已确认：

- 拖放仅指 FileButler 内本地窗口与 115 窗口之间，不包括操作系统资源管理器与浏览器之间。
- 上传支持校验秒传，校验阶段也显示进度和速度。
- 有进度的任务提供非阻塞弹窗；右下角依次为“取消”“后台运行”。
- 任务始终在后端执行。“后台运行”和关闭按钮只隐藏弹窗，关闭浏览器不取消任务。
- 成功完成后弹窗自动消失；失败或部分失败保留错误；取消确认停止后关闭。
- Go 主服务管理常驻 Python 工作进程，通过 p115client 接入 115。
- 可以按功能提交，不要求全部集中在一个 commit；本设计不授权推送、发布或升级版本。

## 首版边界与默认选择

首版连接一个 115 账号，支持扫码登录、登录状态、退出登录、目录浏览、新建目录、重命名、多选复制/移动/删除、上传、下载和在线解压。账号凭证仅保存在服务端。账号失效时明确要求重新登录，不静默切换账号。

“文件读写”在本版指文件管理与上传下载，不自动扩展为云端文本编辑器、媒体播放器、分享、回收站管理或云端 PowerRename/SuperRename。目录上传下载递归处理普通文件和目录；遇到本地符号链接先明确报错，不隐式跟随造成越界。云端目录按需分页读取，不预先扫描整个网盘。

关闭浏览器后继续执行，不等于服务重启后自动恢复。沿用现有内存任务存储；本版不承诺服务进程退出后的任务恢复或断点续传。重新打开浏览器时恢复当前服务实例的任务快照。

## 架构与职责

保留 Go HTTP 主服务作为唯一浏览器入口，使用现有管理员认证保护全部云盘 API。增加独立云盘适配模块，不把 115 ID 当成本地路径，不扩大现有本地 roots 权限。

Python 工作进程负责 p115client 调用、登录会话、上传校验及传输、云端任务查询。Go 负责授权、参数校验、本地路径解析、任务生命周期、限流和 SSE 通知。采用私有标准输入/输出 JSON 消息协议，包含请求 ID、任务 ID、响应、进度事件与取消指令；标准错误仅输出脱敏日志。不开放新的网络监听端口。消息尺寸有界，文件内容不走 JSON 管道。

Go 使用固定命令与参数启动进程，不拼接 shell。工作进程启动握手验证协议版本，通信失败时将受影响任务标为失败；不盲目重试可能已生效的复制、移动、上传或解压操作。重启工作进程只恢复服务能力，不重放不确定状态的任务。无 Python 或依赖不可用时，本地文件功能仍可使用，115 入口显示明确错误。

本地路径先由 Go roots 解析器验证，工作进程只接收已验证的任务参数。下载文件名逐层校验，拒绝路径穿越、绝对路径及符号链接逃逸；写入目标再次检查边界。使用临时文件下载，完成后再发布最终文件，取消或失败清理本任务的临时文件。不覆盖未授权的已有文件。

容器内一起打包 Python 运行环境及锁定版本的 p115client 依赖；非容器部署说明所需 Python 环境和启动配置。凭证使用受限权限文件保存，不进入静态目录、Git、API 响应或日志；归档密码仅用于本次操作，不持久化进任务记录。

## 云盘窗口与拖放

新增“115 网盘”桌面入口，应用图标纵向排列。窗口使用现有窗口框架，独立保存当前目录、选择、导航历史和滚动状态；未登录时显示登录界面，登录后显示文件列表和基本操作。

拖放载荷明确区分本地 root/path 与 115 account/file ID。跨存储拖放默认是复制：本地拖入云盘为上传，云盘拖入本地为下载，成功后保留源文件。支持多选文件和目录，不把跨存储拖放解释为删除源文件的移动。沿用已有本地到本地操作语义。

目标冲突首版默认不覆盖：任务记录冲突项并报告部分失败；不静默覆盖、自动删除或合并同名目标。创建任务后前端立即得到任务 ID，具体传输不依赖提交请求持续连接。

## 上传与秒传

上传流程区分扫描、校验、等待服务端、实际上传与完成。校验读取真实文件计算所需摘要，并执行 115 要求的校验；统计已读取字节和读取速度。需要额外分段校验时继续标记为校验阶段，不把读取速度显示为上传速度。

命中秒传直接完成该文件；未命中自动进入普通上传。阶段切换重置该阶段速率估计，不用摘要读取量充当已上传字节。批量任务同时显示文件完成数和当前阶段字节进度。文件在校验/传输期间变化时报告失败，不继续使用过期摘要声称成功。

上传后的完成状态以 115 接口确认结果为准，不以本地读取到 EOF 为准。账号权限、风控和限流错误明确展示；只对可安全重试的读取操作进行有界退避。

## 在线解压

支持选择云端压缩包、输入可选密码、选择云端目标目录，调用 115 在线解压，不下载到本地解压后重新上传。密码错误允许用户重新输入；不支持的格式、大小、分卷或账号限制显示服务端原因。

根据上游源码，解析压缩包接口 `extract_push` 接受 `secret`；解压到目录是后续操作，不能把解析完成误报为全部解压完成。上游还注明解压到目录不可并发、不可中止，因此按账号串行调度，完成检查以云端实际任务状态为准。

前端依旧使用 SSE，不定时刷新文件列表。115 未提供对应推送时，由后端对活动云端任务做有界状态查询，并通过 SSE 发布状态；这不等于浏览器轮询。只在最终完成/失败后刷新受影响目录。

如果上游解压任务已进入不可中止阶段，“取消”不可用并说明原因；不能把停止查询伪装为取消远端任务。“后台运行”始终可用。

## 通用任务进度

保留现有文件项计数和状态机，新增可选的阶段、当前文件、阶段字节完成量/总量、字节速度、预计剩余秒数及可取消能力。未知总量或无法估计时显示“计算中”或“—”，不虚构百分比或倒计时。ETA 明确对应当前阶段，不把校验剩余时间宣称为完整上传剩余时间。

本地复制按实际读取/写入上报字节；已有实际传输型移动同理。原子重命名式移动和云端服务端复制/移动没有可观察的字节传输速率，只显示实际可知的项目进度和状态，不为了速度展示改变其执行语义。

速率由后端按单调时间和滑动采样计算，阶段切换清空旧样本。进度事件节流，但最终状态立即发布。任务快照包含最新进度，重连后可恢复；旧类型任务没有字节字段时继续按项目数展示。终态不可被迟到的进度事件覆盖。

取消可中止的字节任务时，在分块边界检查取消信号，停止后清理本任务未完成临时产物；已经完成的文件不自动回滚。完成与取消竞态以实际终态为准，不把已完成工作误报为取消。

## 进度弹窗

对于本次创建且有进度的复制、传输、校验、解压任务，展示按任务 ID 绑定的非阻塞进度弹窗。多个任务的弹窗状态独立，支持从任务面板重新打开，不遮断其他文件窗口操作。重新加载页面不强制弹出全部历史任务。

弹窗显示操作类型、源/目标概要、当前文件、阶段、文件项计数、字节进度、速度和阶段剩余时间。未知信息隐藏或标为“—”。右下角顺序固定为“取消”“后台运行”。

- 成功：自动关闭对应弹窗，原有终态通知驱动目录刷新。
- 失败/部分失败：保留并显示原因；已隐藏的弹窗不强制重开，由任务面板显示错误。
- 取消：按钮进入等待状态，后端确认终止后关闭；不可取消的阶段说明原因。
- 后台运行/关闭：仅改变前端可见性，既不取消，也不创建新任务或改变后端优先级。
- 浏览器退出：不触发后端取消；后端任务上下文不从 HTTP 请求或 SSE 连接继承生命周期。

弹窗不负责触发刷新，避免弹窗关闭、完成事件和任务面板三处重复刷新。沿用既有目录滚动位置保持逻辑。

## 验证与提交边界

按能力分别提交：通用字节进度和弹窗、Python 桥接与登录、云盘文件管理和桌面入口、上传秒传与双向拖放、在线解压及部署整合。每个提交保持可构建；不强求一个提交包含全部功能。

使用假 115 适配器覆盖成功、错误、密码错误、限流、进程崩溃和不可取消状态，不要求测试环境持有真实账号。真实账号联调另行由用户授权登录，只在专用测试目录执行写入。

后端覆盖进度与终态竞态、请求断开后任务继续、分块取消、路径穿越、目标冲突、凭证脱敏、校验命中及回退上传、阶段速度计算。前端覆盖图标排列、云盘独立导航、跨窗多选拖放、弹窗后台隐藏/重开、成功自动消失、错误保留和终态刷新。

验收时执行 Go/Python 单元测试、前端测试/lint/build，并使用临时文件目录验证真实本地复制进度及浏览器关闭后的任务执行。真实 115 功能未联调时明确标注，不把模拟测试当作真实秒传或解压验证。
