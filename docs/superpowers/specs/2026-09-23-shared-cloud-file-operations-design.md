# 本地与115共享文件操作、双向剪切及跨文件系统移动

## 目标与边界

把115窗口接入现有文件管理交互，而不是保留两套拖放、剪贴板和操作确认界面。以下包含本轮对话中尚未实施的全部要求：

- 115预览中的“正在直接从115加载…”移动到“重新获取直链”“复制直链”两个按钮右侧，与按钮同一行，加载完成或失败时消失，不单独占一行。
- 本地和115共享拖放浮层、目标反馈、剪贴板、快捷键作用域以及复制/移动/删除预览确认UI。
- 支持115内部复制/移动/删除，115到本地下载/剪切，本地到115上传/剪切。
- 本地移动补齐跨文件系统时的复制后删除回退。
- 替换已被共享实现覆盖的115旧代码，不保留双轨实现或无必要的兼容层。
- 按功能提交，完成后更新8082测试服务；不推送、不发布版本。
- 其他潜在可复用项只检查并在最终报告中列出，不扩大实施范围。

保留上一轮已实现但未提交的预览类型过滤、精简直链工具栏和复制直链改动。作为相关预览功能提交的一部分，不覆盖或丢弃。真实115账号的破坏性联调仅能使用用户另行指定的测试数据；默认使用模拟接口验证删除步骤。

## 当前实现与方案选择

当前本地使用 `FileDragOverlay`、`fileDrag`、`appClipboard` 和 `OperationPreviewContent`；115另有模块级剪贴板和固定下载浮层，上传/下载在松手后立即提交，云端粘贴也直接提交，没有共享预览确认。本地 `OpMove` 仅调用 `os.Rename`，没有处理跨文件系统错误。

选择“共享交互与预览组件，按存储来源适配执行”的方案：

- 相比保留115单独UI并复制样式，共享实现能统一选择、快捷键、剪切状态、冲突和确认行为，符合用户要求。
- 相比将所有本地与云端后端重写成一个文件系统，共享前端流程并适配现有接口的改动边界更清楚；本地路径和115目录ID仍分别校验，保留已有本地操作与115传输实现。

不把115文件ID伪装成本地路径交给本地操作接口，也不让云端内部复制经由本地下载再上传。

## 统一操作语义

| 来源 → 目标 | 复制 | 移动/剪切 | 拖放默认 |
| --- | --- | --- | --- |
| 本地 → 本地 | 原有复制 | 同文件系统直接移动；跨文件系统复制成功后删除 | 原有同根移动、不同根复制 |
| 115 → 同一115账号 | 115 API复制 | 115 API移动 | 移动 |
| 115 → 本地 | 下载，保留云端源文件 | 下载成功后调用115删除API | 复制，显示“下载到…” |
| 本地 → 115 | 上传，保留本地源文件 | 上传成功后删除本地源文件 | 复制，显示“上传到…” |

有效的复制/移动预览均允许切换操作类型，切换后重新生成预览及相应删除警告。剪贴板粘贴默认沿用复制或剪切时的操作，仍可在预览中切换。原有同目录、自身和子目录禁用规则继续适用，不新增同目录自动重命名副本功能。

## 拖放与目标反馈

统一使用现有文件名浮层、图标、多选计数、灰色目的地说明、无效目标标记及红蓝边框。

- 鼠标在FileButler桌面空白处，没有有效目标：只显示文件名及已有多选计数，不显示固定的“下载到本地”，松手不执行。
- 115内有效目标：显示“移动到〔目标文件夹〕”，目标蓝色边框。
- 115拖入本地：显示“下载到〔目标文件夹〕”；本地拖入115：显示“上传到〔目标文件夹〕”。选择移动后的预览明确说明完成后删除来源。
- 原目录、自身或其子目录等无效目标：现有禁止标记、红色边框，阻止提交。
- 多个重叠窗口、最上层命中、行目标和窗口空白目标沿用已有规则；弹窗遮挡、未登录、目录加载失败等情况下不得接受拖放。
- 拖放源和目标携带存储类型、根/账号、父目录、稳定文件ID或本地相对路径、显示名称等必要信息。云端祖先判断使用目录ID和路径祖先信息，不对ID做字符串前缀比较。
- 界面能即时判断的无效目标立即反馈；后端预览及实际执行再次验证源和目标，不能依赖前端红蓝框保证安全。

## 共享剪贴板与快捷键

只保留一份应用级文件剪贴板，沿用 `appClipboard` 的选中文件快照、复制/剪切类型及时间/身份标识，补充存储类型与115账号绑定。

- 本地和115窗口的工具栏、右键及Ctrl+C/X/V都进入同一套动作逻辑；统一显示剪切淡化状态及复制/剪切通知。
- 活动窗口决定快捷键目标，输入框、文本编辑器、对话框中的编辑行为不被文件快捷键抢占。保留本地既有Ctrl+A、Backspace等作用域，不顺带扩展快捷键。
- 应用剪贴板用于文件操作；“复制直链”写系统文字剪贴板，不覆盖文件剪贴板。
- 新复制/剪切替换旧内容；移动任务被成功接受后，只清除仍对应该次源快照的剪切内容，不清空用户随后复制的新内容。取消预览或提交失败不清除。
- 退出或切换115账号时，使原账号相关的剪贴板、预览和拖放失效，不能把旧ID带到新账号；纯本地剪贴板不受影响。
- 删除 `cloud115Clipboard` 及其独立状态和旧入口，调用方迁移完成后不保留备用分支。

## 共享预览与确认

扩展现有 `OperationPreviewContent` 所需的预览和执行接口，保留同一份列表、操作切换、加载/冲突/错误展示和确认按钮。为本地和115相关操作提供适配，不复制整套弹窗。

- 桌面模式沿用窗口内的操作弹窗；精简模式沿用原有对话框。拖放以目标窗口承载确认，粘贴以目标窗口承载确认，删除在来源窗口确认。
- 拖放、粘贴、删除都先预览，用户确认后才建立后台任务。预览只读，不创建目录、不传输文件、不删除文件。
- 预览以名称和用户可理解的目录展示源/目标，不把数字ID作为文件名展示。
- 115到本地移动警告：“下载成功后将删除115上的源文件。”
- 本地到115移动警告：“上传成功后将删除本地源文件。”
- 复制时不显示删除警告；切换为移动立即显示，切回复制立即移除。
- 预览检查不存在的源、目标冲突、非法目录关系、权限/账号及不支持的特殊文件。确认时重新检查关键条件；已有文件不得静默覆盖或把不完整目录合并成成功。
- 后端确认与执行绑定账号和预览所选的稳定源身份，不能信任浏览器传入的绝对本地路径；本地访问继续通过根目录解析与边界限制。
- 任务实际提交失败时留在弹窗显示原因；确认成功关闭预览，任务继续使用现有后台队列、SSE、进度窗口和终态刷新。

## 双向跨端移动

复制与移动共用传输实现；移动仅在对应源项传输成功后增加删除阶段，由后端完成，不能依赖浏览器收到完成事件再请求删除。

- 以用户选择的顶层源项为完成单位。文件成功后才允许删该文件；目录必须整个目录传输成功后才允许进入源目录删除阶段。多选允许部分成功，但失败/取消的源项不能删除。
- 上传沿用现有115秒传识别及上传成功响应；下载沿用字节数检查、流内SHA-1和临时文件落盘后发布。
- 不新增传输后的完整文件哈希重算、下载回读或上传后重新下载。秒传已有的源文件读取不重复执行；流内摘要不造成额外磁盘读取。
- 保留读写错误、关闭/必要落盘、取消、源身份/大小/时间变化等基本检查。目录在传输过程中新增或变化的条目不能被随后递归删除：删除仅针对确认已传输且未变化的源条目；遇到变化保留源并报告未完成。
- 本地源删除不跟随符号链接、不删除根目录、不删除替换到原路径上的其他文件；云端删除使用已绑定账号的文件ID，并在删除阶段重新核对必要元数据及目录成员。
- 取消或失败发生在传输阶段时不进入源删除；删除前再次检查取消状态。已发送的云端删除请求不能承诺撤销，界面如实反映不可取消阶段及结果。
- 目标传输已完成但源删除失败，保留目标副本并报告“传输成功，源文件删除失败”，不得标记为完整移动成功，也不自动重做传输或盲目重试删除。
- 发生取消、失败或进程中断时不隐式回滚其他已成功项；不把这次改动扩展为持久化断点续传/分布式事务。无法确认云端删除结果时明确提示核实，不冒充成功。

115内部复制、移动、删除仍由115 API完成；服务器只做必要的规划、API调度和完成确认，不搬运这些操作的文件内容。本地与115跨端传输仍走现有后端传输通道，与浏览器直链预览是两件事。

## 本地跨根/跨文件系统移动

“不同配置根”不等于“不同文件系统”。保留同一文件系统下直接移动的快速路径，避免本可瞬间完成的移动变成全量复制。

- 同一文件系统：继续直接移动，并保持不覆盖目标的规则。
- 只有确认为跨文件系统错误时，回退到复制成功后删除。权限不足、路径错误、目标存在等其他错误不能被当成跨盘复制理由。
- 文件、目录和符号链接沿用本地已有语义：符号链接复制链接本身，不读取或删除链接目标；不支持的特殊文件明确报错。
- 复用现有字节进度、速度、剩余时间与取消机制，不新增整文件哈希校验。文件关闭/必要落盘成功、复制完整、源未发生可检测变化后才删除。
- 复制失败、磁盘不足、取消或目标冲突保留源。目录必须完整复制成功后才进入源删除阶段；删除不覆盖新出现/变化的条目。源删除失败时保留完整目标并明确报告部分完成。
- 不静默覆盖竞态中新出现的目标；临时/部分目标的清理仅处理本次任务创建且仍可确认身份的内容，不删除已有或外部改写的文件。

## 旧实现清理与保留项

直接替换115专用固定拖放浮层、独立剪贴板、松手直接提交分支、粘贴直接执行分支以及被共享预览覆盖的复制/移动/删除确认代码和过时测试。

115特有且仍必需的登录、目录API适配、离线下载、在线解压、秒传及云端重命名执行保留；它们不是“重复UI”而是存储服务差异。新建文件夹、重命名等本次未明确要求迁移的其他流程，只审查复用机会，不顺带重构。

## 验证与提交边界

按可独立验证的功能提交，必要时调整顺序：预览类型过滤/工具栏及加载提示；本地跨文件系统移动；共享预览与115操作适配；共享剪贴板和拖放；双向跨端移动及旧实现清理。每个功能提交带相应测试，不要求按用户消息逐条提交。

验收覆盖：

- 加载文字同一行和结束消失，原有图片/视频/文本预览及复制直链不回归。
- 拖放四种来源目标组合、无目标、同目录、自身/子目录、多选、前后窗口遮挡、红蓝边框、浮层文字。
- 共享剪贴板替换、剪切淡化、快捷键作用域、粘贴预览、账号变化和提交期间新剪贴板不被错误清除。
- 复制/移动切换、删除警告、预览只读、确认前零变更、目标冲突和执行时重新检查。
- 云端内部操作只调用对应API；跨端移动的传输成功/失败、大小或流摘要异常、取消、源变化、目录成员变化、删除失败和结果不确定。
- 本地真实或可控模拟的跨文件系统错误回退、同文件系统快速路径、其他错误不回退、目录/链接、写入失败、取消、目标竞态及删除失败；只操作临时测试数据。
- Go测试及相关竞态测试、Python测试、前端单测/lint/构建、浏览器回归。重启8082前检查活动任务，避免中断用户测试。

最后报告功能提交、验证结果与真实115验证边界，并单列其他可复用项。未经用户指定，不操作真实网盘文件进行移动或删除测试。
