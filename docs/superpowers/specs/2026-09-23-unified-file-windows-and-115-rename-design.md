# 文件窗口统一与115批量重命名设计

## 目标与当前状态

按用户要求，让115窗口尽量复用普通文件窗口的操作、导航、列表和弹窗，同时接入 PowerRename 和 SuperRename。按功能分别提交，不将元数据开关误当作整个需求完成。

已经完成：115基本文件管理、双向拖放、离线任务提交；普通HTTP打开115窗口修复；PowerRename元数据读取默认关闭，本地允许开启，共用组件在115上下文禁用。

本设计涵盖剩余工作。设计确认后直接实现，不另加执行计划文档。

## 复用方式

选用“共用界面与规则，分别提供本地和115操作”的方式：复用或适度抽取 ActionToolbar、菜单动作渲染、FilePane、PaneStatusBar、WindowDialogLayer、PowerRenameContent 和 SuperRename预览组件。

不复制一套仅外观相似的115界面，避免菜单、选择和导航行为分叉；也不把115文件ID伪装成本地文件路径交给本地执行器。暂不引入面向任意云厂商的大型通用框架。

云端条目保留稳定文件ID、父目录ID及展示路径。本地路径和云端ID的解析、权限检查、扫描、执行由各自的适配层负责。复用组件不得自行用本地API读取云端目录。多个115窗口共享账号，但各自维护导航、选择和滚动状态。

## 工具栏与菜单

### 普通文件窗口

- 保留原工具栏操作，在“新建文件夹”和“删除”之间插入独立的“更多”分组，两侧分隔。
- “更多”使用与右键一致的菜单视觉、动作定义、禁用条件和子菜单渲染，列出当前工具栏没有直接显示的操作，包括在新窗口中打开、复制、剪切、粘贴、选择源连接点，以及适用时的取消选定连接、创建为子菜单。
- 工具栏“更多”的目标由当前目录和选中项决定，不沿用上一次右键目标；右键仍按实际点击目标和当前多选规则确定作用对象。
- 精简模式保留原有跨面板操作，不因新增“更多”删除现有能力或重复列出已经直接显示的动作。

### 115文件窗口

工具栏分组为：重命名、PowerRename、SuperRename、新建文件夹 | 离线下载、在线解压 | 更多 | 删除 | 退出登录。

- 普通复制、剪切、粘贴、在新窗口中打开等放入“更多”，与右键共用动作逻辑；跨115窗口的复制/剪切/粘贴共享云端剪贴板。
- 115右键提供适用的普通文件操作，增加离线下载、在线解压，不显示任何连接点操作。即使本地已选中连接源，也不显示取消连接、创建为、硬链接或软链接。
- 在线解压仅在选中一个可识别压缩包时可用，目录、普通文件、空选择及多选均禁用。文件名识别与后端可接受的压缩包范围一致；格式识别不保证115一定能解压，服务器返回的失败仍需显示。
- 文件夹右键离线下载保存到该文件夹；文件右键、空白右键及顶栏入口保存到当前目录。
- 退出登录位于删除右侧，独立分隔；不影响已有账号忙碌时禁止切换的保护。

### 菜单高度

去除右键菜单固定320px上限，并让“更多”菜单使用相同策略。优先完整展示并根据浏览器视口调整弹出方向和位置；只有菜单本身超过视口可用高度时才允许滚动。保留上下安全边距、键盘导航和子菜单可达性，不以文件窗口内部高度限制菜单。

## 115窗口内弹窗

离线下载、在线解压复用窗口内弹窗层，位置和遮罩限制在所属115窗口内，与普通文件窗口的重命名等弹窗一致。打开弹窗不阻止操作其他文件窗口。已有115新建、重命名、删除确认也采用同一窗口内弹窗机制，替换临时内联表单。

- 弹窗打开时固定目标目录ID，后续导航不能悄悄改变提交目录。
- 离线下载输入框 placeholder 为“支持磁力、ed2k、HTTP/HTTPS、FTP，每行一条”，灰色、无句号，输入后自然隐藏。
- “保存到：xxx”不带结尾句号。
- 去掉“提交成功仅表示115已接受任务，不代表下载完成。”说明；成功结果仍写“已提交到115”，不写“下载完成”。
- 保留离线链接去重、逐条提交结果、失败项保留和网络不确定结果提示。
- 在线解压保留可选密码、创建以压缩包命名的新目录、不覆盖已有目录等既有语义。
- 后台任务生命周期不依赖窗口或浏览器，成功任务按现有SSE终态刷新，不改成前端轮询。

## 115导航、文件列表和状态栏

- 根目录框显示登录的115账号名称，不是FileButler管理员名。由服务端返回经过筛选的账号展示字段，凭证始终留在服务端；暂时无法获取名称时显示“115网盘”并允许刷新重试。
- 共用返回、前进、上移、路径输入框、路径段快捷跳转以及刷新按钮的布局与目标提示。
- 路径输入由115目录适配层解析到目录ID。找不到目录、同名导致定位不唯一或无权限时明确报错，保留原目录；不能回退到根目录冒充成功。
- 共用名称、类型、大小、日期等列的表头、显示、排序、列宽、选择以及刷新保留滚动位置逻辑。不伪造云端缺失字段，缺失日期或本地特有属性显示空值/占位。
- 目录分页不能导致“只排序一页却看似全目录有序”。初版由云端适配层分页收集当前目录，显示加载状态，取得完整列表后才发布给共用列表进行排序和全选；加载失败或切换目录时丢弃未完成结果，不能把半页数据视为完整目录。批量预览同样必须获取完整目标范围后才能执行。
- 保持已有本地与115窗口间拖放上传/下载，不能因复用FilePane把云端文件误路由为本地操作。
- 移除“选择已加载项”独立行，使用普通列表的选择方式和表头选择控件。
- 移除底栏“与本地文件窗口拖放可上传/下载，保留源文件”，总项数显示在右侧，选择数等其他信息沿用普通状态栏。

## 115 PowerRename

- 共用普通PowerRename界面、规则、预览、冲突提示和窗口打开方式，云端提供独立预览及后台执行入口。
- 支持已有基于名称的搜索替换、正则、大小写转换、目标部分选择、编号、补零及其他不读取文件内容的规则；自然排序和选项语义与本地一致，不重新实现另一套字符串替换引擎。
- “修改文件属性”在115下始终灰色、未勾选；服务端同样拒绝云端元数据读取请求。不能仅依赖禁用前端控件，也不能继承本地已勾选状态。
- 云端元数据占位符明确提示不支持，不自动下载文件获取EXIF/XMP，不修改文件内部属性。
- 预览与执行使用同一个确定的计划；涉及随机替换时不能在提交阶段生成不同于预览的名字。执行前校验文件ID、原名称、父目录及目标冲突，过期预览要求重新生成。

## 115 SuperRename

- 共用媒体扩展名识别、自然排序、编号位数、视频V前缀、预览投影和树状界面。
- 图片在所属组目录中编号；视频在该目录的“视频”子目录中以V前缀编号，不覆盖已有目标。
- 共用文件/文件夹勾选、取消勾选仅重排所属组、不匹配项醒目标记、默认不展开未启用深层目录及用户勾选后按普通组处理的逻辑。
- 保留每组最右侧固定“重命名”按钮、单组执行、成功后移除该组，以及整批执行能力；不得在任务刚提交时提前移除组或刷新。
- 扫描通过115分页目录接口取得所需数据，不下载图片或视频内容；按用户启用的范围扫描，不无条件递归整个网盘。

## 云端执行与错误处理

- 沿用Go后台任务、Python provider和SSE，关闭浏览器不取消已创建任务。预览请求只读，执行请求需要认证并校验账号与文件范围。
- 账号切换、退出登录、并发批量操作应受现有任务保护，云端写操作受控串行，避免多个组互相覆盖。
- 云端目录扫描输出与共用规则兼容的输入，并维护路径到文件ID的映射；执行前重新核对父目录、原名、占用目标，不能把客户端提交的任意目标计划直接照单执行。
- 处理名称互换、临时占位改名、视频目录创建和移动等多阶段步骤，记录必要的操作状态。网络超时不能等同于“操作未发生”，应先根据稳定文件ID核实再决定后续步骤，禁止盲目重试不确定写入。
- 仅在确认所有所需改名/移动完成后报告成功。部分失败保留明确结果，尽可能恢复本次操作且不触碰外部新修改；无法安全恢复时停止并给出已完成、未完成及残留状态，不承诺云端事务原子性。
- 取消在安全边界生效；已发出的不可中断请求等待结果或核实状态，必要的收尾/恢复完成后才报告取消。
- 任务状态为后端权威；单组和整批任务完成后按原逻辑刷新相关文件窗口，同时保持滚动位置。
- 服务重启后的自动任务续跑不在本次范围，失败恢复记录不得包含登录凭证。

## 验收与提交边界

按独立可验证功能拆分提交：公共工具栏和菜单；115公共文件窗与账号/路径数据；115窗口内弹窗和文案；云端PowerRename；云端SuperRename。必要时再拆扫描、规划、执行等内部改动，但不能用只有界面入口的提交冒充功能已完成。

测试覆盖：本地现有行为不回归；菜单普通视口完整显示、小视口可滚动；115不泄露本地连接点动作；非压缩包不能解压；多窗口导航、选择、剪贴板和弹窗隔离；默认不读取元数据及云端服务端禁用；分页扫描、重名冲突、过期预览、名称互换、部分失败、取消、浏览器关闭后任务继续；多组/深层组勾选与单组完成后移除；普通HTTP访问和双向拖放。

通过单元测试、Go竞态检查、前端编译/lint和浏览器测试后更新8082临时服务。重启前检查运行中的任务，避免中断用户操作。真实115账号测试只能在明确指定的测试文件范围内执行，不对用户其他网盘文件做写入试验；未做真实联调的部分需明确说明。默认不推送、不发布版本。
