# 本地与115详细信息窗口设计

## 目标与范围

给本地及115文件窗口提供共用的独立“详细信息”窗口，查看文件、文件夹或多选项的基本属性、大小、媒体信息及已有 SHA1。样式参考用户截图，不含“常规/权限”页签、所有者，保留名称区下方分隔线。通过现有窗口体系支持拖动、聚焦、关闭及同时打开多个窗口，不修改文件内容。

本设计记录已确认的交互；书面设计审阅通过后直接实施，不另写执行计划。

## 接入方式与方案选择

采用共用窗口与统一数据模型，本地和115分别提供数据适配。复用文件动作菜单、窗口框架、类型标签、预览类型判定和 SQLite SHA1 存储。相比各自编写窗口，这样能保持交互一致；相比打开窗口时同步读取所有数据，分阶段加载能避免目录统计阻塞界面。

现有 `FileActionMenuItems` 已支持菜单分隔；在共享动作层接入详细信息，不为右键和顶部更多分别复制实现。现有 PowerRename 的 XMP 提取使用整文件 `os.ReadFile`，本功能不调用该读取流程，也不顺带改动 PowerRename。

## 入口与目标

- 右键及顶部“更多”菜单最后增加分隔线和“详细信息”，位于删除操作之后；不增加独立工具栏按钮。
- 文件项右键沿用当前选择规则；多选打开一个合并窗口。
- 空白处右键明确针对当前目录，不误用保留的文件选择；顶部更多无选择时也针对当前目录。
- 打开时固定目标与选择顺序，之后原窗口导航、选择变化不改变已打开详情。
- 115未登录或位置未就绪时禁用入口。

## 窗口展示

顶部显示图标和名称，标题为“详细信息 - 名称”。多选名称为“第一个文件/文件夹名 等 X 项”，X 为原始选中项目数，不因递归去重而改变。

字段顺序：类型、分辨率（适用时）、时长（适用时）、大小、占用空间、共包含（适用时）、位置、修改时间、创建时间、SHA1（含右侧按钮）。

### 单选

- 文件类型直接复用文件列表的类型显示；文件夹显示“文件夹”。
- 仅按现有预览类型判定为图片/视频的文件出现媒体字段。图片显示分辨率，例如 `3840 * 2160`；视频再显示时长，例如 `00:17:02`，小时允许超过两位。
- AVI 等不在现有预览支持范围的文件与普通文件一样，不出现媒体字段。不以探测成功与否扩展预览支持范围。
- 单选文件不显示“共包含”；单选文件夹显示递归包含的文件与文件夹数，不计该文件夹本身。
- 修改时间、真实创建时间按现有界面时区显示。没有创建时间时显示 `--`，不以 ctime 或修改时间替代。
- SHA1 行默认查有效数据库记录；无记录显示 `--`。文件夹显示 `--` 且禁用“重新获取”。

### 多选

- 类型标签完全一致时显示该类型，否则显示“多种类型”（包括文件与文件夹混选）。
- 隐藏分辨率、时长、修改时间、创建时间和整个 SHA1 行。
- 大小和占用空间显示去重后的合计。
- “共包含”计入所选文件、所选文件夹及其后代；父子同时被选中时同一项目不重复计算。
- 共同父目录作为位置并允许复制；不同父目录显示“多个位置”，复制按钮禁用。

### 数值、路径与未知值

- 大小沿用项目单位进位惯例，自适应单位、最多两位小数，并显示精确字节，例如 `64.44 KB（65,982 字节）`。字节和数量采用三位逗号分组，不以舍入后的单位值反推字节。零值正常显示，不等同未知值。
- 单选位置显示父目录，根目录显示自身。旁边的“复制原始路径”复制该位置的完整路径：本地为服务器文件系统绝对路径，115为网盘完整路径，不是下载直链。
- 复制成功给予轻量反馈，失败明确提示，不谎报成功。
- 缺失或不支持的字段显示 `--`；加载中有明确状态。目录大小、可统计的占用空间和包含数量初始显示“计算中...”，完成后替换。
- 115物理占用空间不可知，直接显示 `--`，不拿逻辑大小冒充占用空间。

## 数据与目录统计

增加认证保护的信息读取接口，目标仅接受现有本地 root/path 或115账户上下文中的文件 ID。数据模型区分未知、加载、完成、失败，包含字节数、数量、时间、路径、媒体字段、缓存 SHA1；不可用值为 null，不用零填充。

基本信息先返回；目录统计和媒体探测分别异步请求，互不阻塞。前端不轮询，读取请求完成即更新窗口。每个窗口独立状态，使用取消信号与请求标识防止关闭后或旧请求覆盖结果。

本地读取文件系统属性；Linux 占用空间按已分配块统计，其他无法可靠提供的平台返回未知。文件夹逻辑大小累计后代文件内容大小，不把目录结构自身的 size 当作内容大小；占用空间计入统计范围内的目录及文件分配块。

递归不跟随软链接，不越过配置根的访问边界。软链接按链接本身计数和属性处理，不为其目标计算 SHA1 或媒体信息。多选先按规范化目标消除重复及父子覆盖；本地不同路径的硬链接在文件项数量和逻辑大小中各计一次，在占用空间中按设备号及 inode 去重。此数值不承诺等于删除后释放空间，尤其存在共享块或压缩时。

115只通过目录/属性 API 获取或累计大小与数量，不下载内容做目录统计；优先使用语义明确的服务器汇总，缺失时分页遍历，限制并发并支持取消。目录在读取中变化、权限不足或部分项无法读取时提示统计未完成，不能将部分和伪装成完整总量。

## 媒体信息读取边界

仅单选受支持的媒体类型才探测。图片解析尺寸字段，视频解析容器元数据；允许跳转到文件尾，但不解码全部画面，不扫描整文件以兜底。设置每次探测最多 8 MiB 内容读取及 10 秒超时；小文件可能完整落在读取预算内，这不等于对所有文件执行全量扫描。

本地使用有累计读取预算、可随机访问的读取层。115优先使用属性 API 中可信的原始分辨率、时长；缺失时只做受预算约束的直链 Range 读取，不请求转码视频替代原文件属性。远端不支持所需分段访问、返回异常内容或达到限制时终止并显示 `--`，不退回完整下载。

远端读取复用115直链取得与安全校验能力，不接受浏览器任意指定的 URL；Cookie、带签名的直链不进入日志或持久化详情数据。不使用无读取量约束的隐藏 img/video 加载来声称保证读取上限。

不同格式无法在预算内取得信息时允许显示 `--`，不因某一格式失败而影响其他基本字段。新增解析依赖须与部署构建一起验证，不要求用户在未说明的情况下安装系统工具。

## SHA1 与重新获取

- 默认查询现有 SQLite 缓存并遵守版本匹配和账户/根隔离规则，不因打开详情而计算本地 SHA1，也不为目录递归计算 SHA1。
- 本地点击“重新获取”强制流式读取完整文件，不使用旧值代替计算；前后核对文件身份、大小和时间等版本信息，变化或取消则不提交结果。使用与115传输缓存一致的 scope、路径及版本编码，避免形成第二套不互通的缓存。
- 115点击按钮重新调用原文件属性 API 获取服务器 SHA1，不下载文件自行计算。成功后写回相同账户下的缓存；服务器无值显示 `--`，不继续显示已失效的旧值。
- 计算/获取中按钮禁用并显示状态，避免重复请求。失败显示简短错误，仍允许重试；不能把过期值标成新结果。缓存写入失败与读取成功分别处理并提示。
- 哈希计算与复制等操作不串行排队，但资源并发受限。它属于详情读取请求，不新建持久化后台传输任务；关闭详情时取消尚未完成的探测、统计及哈希请求。

## 安全与范围限制

所有接口沿用身份认证与根目录解析边界，前端不传任意绝对路径供后端打开；复制绝对路径只向已有访问权限的用户提供。115请求与响应绑定当前账户，退出或切换账户后旧窗口不得加载其他账户同 ID 的文件。

不新增迁移代码、不扩展权限编辑、不修改内容、不扫描全部根建立索引、不更改 PowerRename 属性读取开关、不自动发布版本或推送。

## 验证标准

- 菜单末尾分隔、空白目录入口、更多无选择、多选合并、多个独立窗口和关闭取消。
- 单文件/目录/多选字段显隐，统一与混合类型，AVI 无媒体行，图片/视频按预览范围显示。
- 字节分组、零值、单位边界、长时长、未知字段、真实创建时间缺失、路径复制反馈。
- 递归统计、空目录、深目录、父子去重、软链接不跟随、硬链接占用去重、稀疏文件、部分读取失败、115分页及取消。
- SHA1 命中不读内容、手动强制重算、计算中修改文件、缓存失效、账户隔离、115重新获取无下载。
- 媒体读取预算和超时、末尾元数据、无 Range 支持、格式损坏、窗口关闭后不更新。
- Go 与 Python 单元/接口测试、前端交互测试、编译及针对详情窗口的浏览器测试，确保现有预览、菜单和传输不回归。
