# 本地压缩包解压

## 目标与已确认约束

本地文件管理支持解压，复用已有文件窗口、后台任务与进度窗口。用户已确认直接写入目标，不先完整解压到临时目录再复制；默认创建同名文件夹，不覆盖已有目录。输出名称留空时直接解压到所选目录，允许复用普通子目录，不覆盖同名文件。失败或取消保留部分文件并明确提示，由用户自行删除，不删除原有内容。

不涉及 115 远端解压行为修改、SHA1 故障修复、NAS 部署或版本发布。

## 方案选择

- 采用 7-Zip 命令行作为解码后端，Go 负责权限、路径约束、任务生命周期与输出处理。容器安装对应依赖；本机缺少依赖时返回明确错误。
- 不采用逐格式自建 Go 解码器：首版需要常见格式及密码支持，分别维护解码器增加成本。
- 不采用临时目录完整落盘后搬运：遵守直接写入目标的约束，避免跨文件系统额外复制。

具体发行包与命令选项在实现时依据官方文档和实际安装版本验证，不假定所有 7-Zip 发行包支持完全一致的格式。

## UI 与范围

- 普通文件窗口及精简双栏共用本地解压入口：右键、“更多”、压缩包双击。
- 单选可识别的压缩包时启用；不支持批量解压或递归解压嵌套压缩包。
- 窗口内弹窗复用统一 Input、DialogFooter 和按钮样式，包含目标位置、输出文件夹名、可选密码。
- 目标默认压缩包所在目录，可选择已配置根目录内其他文件夹；浏览列表双击进入文件夹，“上移”单击。输出文件夹默认去除压缩格式后缀后的压缩包名；复合后缀如 .tar.gz 整体去除。允许留空，表示不创建外层目录；非空名称禁止路径分隔符及路径跳转名称。
- 首版覆盖 ZIP、7z、RAR、TAR 及常见 gzip/bzip2/xz 压缩 TAR；格式识别不代表保证每个变体均可解码。不支持的格式给出后端实际错误。
- 含压缩层的 TAR 允许解码管道，不把完整中间 TAR 写入磁盘；如果所选后端无法安全完成该流程，明确拒绝该类型，不能悄悄使用额外磁盘副本。

## 后端边界与流程

新增独立本地解压模块，由现有已认证路由提交任务；使用 roots 解析源文件和目标目录，不接受任意服务器路径。

1. 校验源为允许读取的普通文件，目标为允许写入的目录，依赖可用。
2. 检查压缩包条目与输出安全性；支持加密头的压缩包使用所填密码检查。无法可靠检查的压缩包拒绝执行。
3. 非空名称排他创建输出目录，已存在时拒绝，不自动编号。名称留空时使用已有目标目录，在写入前检查全部条目，拒绝文件冲突、文件与目录冲突和链接，仅复用普通目录。写入时仍排他创建文件并以不跟随链接的目录句柄处理并发变化。
4. 启动受控解压，直接写入该目录；输出权限不得保留压缩包中的特权位或任意所有者。
5. 更新现有任务进度；成功后完成任务、关闭进度窗、刷新相关文件窗口。失败或取消也刷新，以显示保留的部分内容。

路径安全必须约束实际写入过程，不能只做一次字符串检查后任由外部进程写文件。拒绝绝对路径、父目录跳转、链接条目、特殊设备条目及输出路径冲突；防止已有或并发替换的链接绕过目标范围。实现时验证所选工具的路径处理，并为外部进程提供限制写入范围的执行边界；如果运行环境不能提供必要边界，应明确失败而非退回不受限执行。

密码不写入任务持久化字段、错误详情、审计日志或公开进度事件，不拼接 shell 命令。实现时确认密码传入方式及进程可见性，不能以隐藏 UI 代替秘密保护。

## 任务、取消与异常

- 使用现有后台任务机制，关闭弹窗或浏览器不会停止；“后台运行”仅关闭窗口。
- 进度窗在目标文件窗口中心出现，成功后自动消失。复用可取消与多任务并行逻辑。
- 进度显示当前条目和后端可可靠提供的进度；无法取得准确总量或速度时显示未知，不伪造百分比或预计时间。
- 取消终止任务所属子进程，确认停止写入后再标为取消。
- 解压失败、密码错误、磁盘空间不足、取消时不自动删除输出目录。提示实际原因、输出位置及“可能保留部分解压文件”。创建输出目录前失败不声称留下文件。
- 不自动解压内嵌压缩包；条目统计与资源限制应在开始写入前检查，不能仅依赖压缩包声明大小保证磁盘安全。磁盘耗尽必须安全失败，不影响已有文件。

## SHA1

解压文件视为新文件，不继承压缩包 SHA1，不为记录 SHA1 再通读文件。已有源压缩包记录不变。

## 验证

- 后端：普通与加密包、中文名称、目标冲突、错误密码、缺少依赖、不支持格式、损坏包、取消及部分文件保留。
- 安全：路径跳转、绝对路径、符号/硬链接、特殊条目、同名重复条目和并发目录替换；验证目标外文件未被创建或修改。
- UI：三个入口、禁用条件、双栏复用、统一弹窗、后台运行、完成及失败刷新。
- 真实文件系统：普通目录和专用 mergerfs 测试目录；确认不进行解压后的全量搬运，不访问生产目录。
- 容器：实际安装的工具可执行，使用真实压缩包做冒烟测试。运行 Go/前端相关测试及构建。
